# Data provenance

The source transcription is Zandbergen-Landini ZL3b.
See [Rene Zandbergen's transcription documentation](https://www.voynich.nu/transcr.html).
EVA denotes manuscript signs, not translated words.

| File | Origin |
|---|---|
| `data/transcription_excerpts.tsv` | Two source lines and corrected views; original line numbers retained |
| `data/corrections.tsv` | Project decisions, supporting readings and Yale scan URLs |
| `data/ambiguities.tsv` | Seven unresolved decisions without forced correction |
| `data/cells_sample.tsv` | All 19 available factorization records in two selected lines |
| `data/cell_provenance.tsv` | Aligned reference readings for those 19 IDs |
| `data/provenance.json` | Hashes of the full source, corrected view and preliminary factorization |

The manuscript is [Yale Beinecke MS 408](https://collections.library.yale.edu/catalog/2002046).
No scans or illustrations are distributed. Scan URLs require network access;
verification scripts do not.

Underlying transcriptions are third-party materials and are not relicensed as
project-owned work. Corrections and annotations are distinct from source readings.
Attribution does not replace permission where required by source terms or law.

Paths in the artifact register identify private archive files, not public
downloads or claims of ownership over third-party content.
